## OpenSpec

OpenSpec 1.15.0 is installed in the sandbox as `openspec`. Use it for
spec-driven changes in the mounted project.

Start a project once with `openspec init`, then follow the generated
`openspec/AGENTS.md` and use `openspec list`, `openspec change`, and
`openspec validate` for proposals and specs. Do not run `npm install` for
OpenSpec; the CLI is already in the image.
